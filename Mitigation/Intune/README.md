# Intune Mitigations

This folder contains Microsoft Intune-based mitigations for ClickFix-style attacks.

Each subfolder contains a specific control with its own detection script, remediation script, and deployment notes.

Use these scripts with Intune Remediations to validate and enforce security settings on managed Windows endpoints.

> Start with a pilot group, validate the impact, and monitor the Intune Management Extension logs before broad deployment.
